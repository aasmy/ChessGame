# ChessGame

## Introduction

ChessGame is a Java chess project designed to practice object-oriented design, clean code, SOLID principles, and design patterns.

The project is built step by step, starting from the core game components and gradually adding pieces, board logic, movement validation, game simulation, and special chess rules.

## Project Goals

- Build a playable chess game in Java.
- Separate the system into clear responsibilities.
- Apply object-oriented design in a practical project.
- Use design patterns only where they make the design cleaner.
- Keep the code readable, extendable, and easy to maintain.
